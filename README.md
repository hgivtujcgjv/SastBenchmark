# SastBenchmark

Наборы тест-кейсов для оценки статических анализаторов (SAST): полнота обнаружения,
устойчивость к синтаксической форме дефекта и распознавание санитайзеров.

> **Внимание.** Репозиторий содержит намеренно уязвимый код. Он предназначен только для
> тестирования анализаторов в изолированной среде. Не разворачивайте его и не переносите
> фрагменты в рабочие проекты.

## Ветки

Каждый набор живёт в отдельной ветке и лежит в корне — клонируйте только то, что нужно.

```bash
git clone --branch go-bench --single-branch <url> go-bench
```

## Идея

Разметка вынесена в отдельную ветку `results`, а сами кейсы её не содержат — прогон
предполагается слепым.

Внутри категории уязвимые кейсы — это **один и тот же дефект в разных синтаксических формах**
(разные методы одного класса, лямбда против method-reference, разные способы интерполяции строки).
Разброс результатов внутри одной категории показывает, что правило анализатора привязано к форме
записи, а не к семантике.

Безопасные кейсы содержат **настоящую митигацию** и часто отличаются от уязвимого одним вызовом
или одним аргументом. Ложное срабатывание на таком кейсе прямо указывает, какой именно санитайзер
анализатор не распознаёт.

Методика подсчёта и оговорки к семантическому зачёту — в ветке [`results`](../../tree/results).
