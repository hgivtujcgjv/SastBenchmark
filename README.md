# SastBenchmark — Spring blindspots

Набор тест-кейсов для проверки полноты и точности статических анализаторов.

> **Внимание.** Код содержит намеренные уязвимости и предназначен только для тестирования
> анализаторов в изолированной среде. Не разворачивайте его и не используйте фрагменты в
> рабочих проектах.

## Состав

- **Кейсов:** 88
- **Идентификаторы:** BenchmarkTest07001 – BenchmarkTest09020
- **Категорий:** 10

| Категория | CWE | Что проверяет |
|---|---|---|
| `lombok` | CWE-78 | поток через геттер, сгенерированный Lombok на компиляции |
| `brokensanit` | CWE-22/78/89/601 | защита присутствует, но не работает |
| `deadcode` | CWE-78 | недостижимый приёмник (проверка на ложные срабатывания) |
| `jwt` | CWE-347 | разбор токена без проверки подписи |
| `csrf` | CWE-352 | отключённая CSRF-защита Spring Security |
| `databinder` | CWE-915 | mass assignment через связывание данных |
| `ldapi` | CWE-90 | LDAP-инъекция |
| `jndi` | CWE-74 | JNDI lookup управляемого имени |
| `springdata` | CWE-89 | инъекция через Spring Data (Sort, native query) |
| `cmdi-springsrc` | CWE-78 | спринговые источники (приёмник фиксирован) |

Требует Lombok, Spring Security, Spring Data JPA (заданы в `pom.xml`).

Разметка **не включена в эту ветку** — прогон слепой. Ключи в ветке [`results`](../../tree/results).

## Структура

обычный Spring Boot 3.5 проект: `src/main/java/local/benchmark/spring/`, `pom.xml`
