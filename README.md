# SastBenchmark — Spring v2 (матрицы форм)

Набор тест-кейсов для проверки полноты и точности статических анализаторов.

> **Внимание.** Код содержит намеренные уязвимости и предназначен только для тестирования
> анализаторов в изолированной среде. Не разворачивайте его и не используйте фрагменты в
> рабочих проектах.

## Состав

- **Кейсов:** 85
- **Идентификаторы:** BenchmarkTest06001 – BenchmarkTest06176
- **Категорий:** 10

| Категория | CWE | Ось |
|---|---|---|
| `cmdi-entry` | CWE-78 | точки входа (приёмник фиксирован) |
| `cmdi-source` | CWE-78 | источники данных (приёмник фиксирован) |
| `redirect2` | CWE-601 | формы приёмника |
| `ssrf2` | CWE-918 | формы приёмника |
| `sqlinj2` | CWE-89 | формы приёмника |
| `pathtraver2` | CWE-22 | формы приёмника |
| `spel2` | CWE-917 | формы приёмника |
| `templateinj2` | CWE-1336 | формы приёмника |
| `xxe2` | CWE-611 | формы приёмника |
| `deser2` | CWE-502 | формы приёмника |

Набор изолирует **один фактор за раз**: в блоке точек входа фиксированы источник и приёмник,
меняется способ вызова кода снаружи; в блоке источников — фиксированы вход и приёмник; в блоках
по категориям — фиксированы вход и источник, меняется форма API-приёмника. Каждый блок содержит
контроль с заведомо детектируемой формой и безопасные контроли с настоящей митигацией.

Разметка (какой кейс уязвим, роль контроля / слепой зоны) **не включена в эту ветку** —
прогон предполагается слепым. Ключи в ветке [`results`](../../tree/results).

## Структура

обычный Spring Boot 3.5 проект: `src/main/java/local/benchmark/spring/`, `pom.xml`
